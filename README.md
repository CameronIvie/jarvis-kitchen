# Jarvis Kitchen

A voice-controlled kitchen assistant for the phone: search the cookbook library, cook step by step, scale recipes by people and meals, and run up to four timers.

Live at: https://cameronivie.github.io/jarvis-kitchen/

Open it in Safari on iPhone, then Share → Add to Home Screen. Tap the brain and talk.
Voice needs Siri & Dictation turned on. The library is sample data for now.
