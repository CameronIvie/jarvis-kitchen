# Bobbity

A voice-controlled kitchen assistant for the phone and iPad: search the cookbook library, cook step by step, scale recipes by people and meals, run up to four timers, and ask what flavors go together.

Live at: https://cameronivie.github.io/jarvis-kitchen/

Open it in Safari, then Share → Add to Home Screen. Tap the brain and talk. You can start with "Bobbity" or just say the request.
Voice needs Siri & Dictation turned on.

## Books

Book content is never stored in this repo. Each scanned book becomes a `.bobbity.json` file that you add on the device
(Library → Add a book file). It is saved in the browser's storage on that device only and works offline.

- "What goes with mascarpone?" / "what pairs with lamb" / "what goes with figs and goat cheese"
- "more" reads the rest of the list
